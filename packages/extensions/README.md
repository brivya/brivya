# @brivya/extensions\n\nPhase 1 Extension Host baseline.\n\nThis package implements the frozen P0-E2 contracts for:\n\n- Extension package/manifest\n- permission grants and permission-expansion detection\n- install plans\n- worker/remote execution boundaries\n- permission-scoped Host API\n- opaque secret bindings\n- Registry Client contract\n\nCore permission rule:\n\nrequested permissions ∩ tenant policy ∩ administrator grant = effective permissions\n\nRuntime boundary:\n\nExtension → Host API → canonical Brivya Runtime / governed platform service\n\nThere is deliberately no raw secret-read Host API.\n\nPhase 1 runtime isolation models worker and remote execution. WASM is deferred, and arbitrary third-party in-process execution is not part of the baseline.\n
